# PulseSort: EMG-Based Hand Gesture Recognition

PulseSort is a machine learning pipeline for recognizing hand gestures using **Electromyography (EMG)** signals. The project focuses on the software pipeline—from preprocessing raw EMG signals to extracting meaningful features and training machine learning models for gesture classification.

> **Note:** This project implements the complete software workflow. The EMG data used for development was pre-recorded, as hardware acquisition was outside the scope of the project.

---

## Overview

Electromyography (EMG) records the electrical activity generated by muscles. Different hand gestures produce distinct EMG patterns that can be analyzed using machine learning.

PulseSort processes raw EMG recordings through multiple stages:

- Signal visualization
- Data normalization
- Sliding window segmentation
- Feature extraction
- Machine learning classification
- Performance evaluation

The objective is to accurately classify different hand gestures using handcrafted time-domain features.

## Features

### Signal Preprocessing

- Raw EMG signal visualization
- Multi-channel signal analysis
- Normalization of sensor readings
- Sliding window segmentation

### Feature Engineering

Time-domain statistical features extracted include:

- Mean
- Mean Absolute Value (MAV)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)

These features are converted into structured datasets for model training.

---

## Machine Learning Models

The project evaluates multiple supervised learning algorithms:

- Logistic Regression
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)

The extracted feature vectors are used to train and compare these classifiers for multi-class hand gesture recognition.
